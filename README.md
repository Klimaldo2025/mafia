# 🎭🏆 Турнир «Спортивная мафия»

Статический сайт турнира — без сервера, только GitHub Pages.

## Файлы
- `index.html` — страница для участников (таблица + номинации)
- `admin.html` — панель ведущего (пароль по умолчанию: `mafia`)
- `app.js` — логика подсчёта
- `style.css` — оформление

## Как выставить в интернет (бесплатно)
1. Создай репозиторий на GitHub и загрузи все файлы в корень.
2. Settings → Pages → Source: `main` branch → Save.
3. Через минуту сайт будет доступен по адресу:
   `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

## Как пользоваться
⚠️ Ведущий — это НЕ владелец репозитория. Аккаунт GitHub ведущему не нужен,
достаточно ссылки и пароля.

1. Владелец после деплоя отправляет ведущему ссылку `.../admin.html` и пароль
   (по умолчанию `mafia` — ведущий меняет его в настройках на свой).
2. Ведущий открывает ссылку на СВОЁМ устройстве, вводит пароль.
   Все данные хранятся в браузере ведущего (localStorage) — владельцу
   доступ к устройству ведущего не нужен, и наоборот.
3. Ведущий добавляет игроков и игры, вносит результаты (роль, исход, фолы, доп. баллы).
4. Нажимает «📋 Скопировать ссылку для игроков» и кидает её в чат клуба.
5. Участники открывают ссылку — видят таблицу и номинации.

## Бэкапы (важно!)
- «💾 Скачать данные» — ведущий сохраняет JSON после каждой игровой
  и присылает файл владельцу или в чат.
- Любая ранее скопированная ссылка для игроков — тоже полный бэкап:
  если открыть её в admin.html, данные предложат восстановить.
- «📂 Загрузить данные» — восстановление из JSON-файла.

## Система очков
- Победа за чёрных (мафия/дон) = 4, победа за красных (шериф/мирный) = 3, поражение = 1
- Фолы за игру: 0–2 = 0, 3 фола = −0.5, 4+ = −1
- Доп. баллы — по усмотрению ведущего (необязательно)

## Номинации
Ролевые (доп. баллы и фолы считаются только в играх за эту роль):
🎭 лучшая мафия, 👑 лучший дон, 🎯 лучший шериф, 🏘️ лучший мирный.
Рейтинг = ср. очки + 0.5×ср. доп. баллы + 0.1×игры − 0.2×ср. фолы.

Специальные: 🚀 активист, 🏆 чемпион, 💎 лидер, 🕵️ лучший следователь.

⚠️ Данные хранятся в браузере ведущего (localStorage) + зашифрованы в ссылке.
Скачивай бэкап кнопкой «💾 Скачать данные» после каждой игровой!
