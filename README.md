# Спортивная мафия — Beget v2

Загрузи содержимое архива в public_html.
Beget поддерживает Python и документирует запуск Python web-приложений через Passenger/WSGI.

## Тактик турнира
Минимум 4 игры. Индекс 0–100:
- 45% — процент побед;
- 25% — средние доп. баллы за игру, относительно лучшего кандидата;
- 20% — средние очки за игру, относительно базовых 4 очков;
- 10% — дисциплина по фолам.

При равенстве: больше побед → больше игр → больше общих очков.

Это оценка на основе данных текущей системы. Она не утверждает, что видит реальные решения игрока. Если позже добавить голосования, убийства, проверки шерифа и т.п., алгоритм можно сделать глубже.
